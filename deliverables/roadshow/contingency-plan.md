# 现场故障与降级预案

## 优先级

1. PPT 内真实截图：主路径，完全离线可讲。
2. 思看科技稳定 Demo：网络或后端异常时使用已核验 Mock/Fallback。
3. 本地录屏：有时间录制后作为次要备份，不替代 PPT 截图。
4. 动态多公司问答：仅在后端、数据库和 DeepSeek 均正常时使用。

## 故障判定与动作

| 情况 | 现场动作 | 不能做的事 |
|---|---|---|
| Wi-Fi 断开 | 留在第 6 页截图，随后跳第 11 页说明离线策略 | 反复刷新拖延时间 |
| DeepSeek 超时或报错 | 切回思看科技稳定问题，使用 Mock/Fallback | 把失败包装成成功 |
| 后端不可达 | 直接用截图讲闭环和 Evidence 抽屉 | 临时改接口或环境变量 |
| 非思看公司失败 | 显示证据不足或服务不可用，返回主线 | 降级为思看科技事实 |
| PDF 外链打不开 | 使用截图中的页码和原文，答辩后再开文件 | 猜测页码或文件版本 |
| 浏览器缩放/排版异常 | 放弃实时页面，回 PPT 截图 | 现场调 CSS |
| 时间不足 | 取消动态公司问答，保留 Evidence 抽屉与水果拒答 | 跳过安全边界 |

## 演示前 15 分钟检查

- PPTX 与 PDF 均能本地打开，16:9 显示正常。
- 浏览器预打开思看科技首页，稳定问题可点击。
- 后端健康、稳定数据库存在，但不打开或修改任何 `.db` 文件。
- 检查投影分辨率和系统缩放；关闭通知。
- 如已录屏，确认本地离线播放且无密钥、Token、终端窗口或个人信息。
- 手机热点只作为网络备援，不改变产品数据源或事实口径。

## 主讲口播

若现场服务异常，只需说：“为了不让网络状态影响事实口径，我们切换到已经核验的稳定演示数据；证据结构和真实产品一致。”随后继续截图路径。
